# N100 Financial Intelligence Platform

## Overview
The N100 Financial Intelligence Platform is a Python-based financial analysis project that analyzes Nifty 100 companies using financial statement data. It calculates important financial metrics, generates investment recommendations, and displays reports with charts.

## Features
- Financial Ratio Analysis
- CAGR Analysis
- Cash Flow KPI Analysis
- Company Dashboard
- Investment Recommendation
- Sector Analytics
- Report Generation
- Data Visualization using Matplotlib

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- OpenPyXL

## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Go to the src folder:
   ```
   cd src
   ```
4. Run:
   ```
   python -m loaders.loader
   ```

## Output
- Financial Ratio Analysis
- Investment Recommendation

- Final Company Report
